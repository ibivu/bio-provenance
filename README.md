## Running the evaluation scripts

To run only the evaluation scripts presented in the manuscript, copy the `.env.example` to `.env`.
Then, go to the `multi_path_analysis.ipynb` and run the notebook.
You can click through different alert nodes and run cells after the selection again to see the impact of each alert node. 
The captured COVID-19 analyses can be run via the `compare_analysis_result.ipynb` notebook. 
The necessary files are available in the `data/` folder.

## Inputs to the pipeline

### External files needed:
`PROTEIN_MAP`:
Biomart mart_export file with columns:
* `Gene stable ID`, 
* `Gene stable ID version`, 
* `Transcript stable ID`, 
* `NCBI gene (formerly Entrezgene) ID`, 
* `Transcript stable ID version`

`EXPRESSION_DATA`; rna-seq data from your experiment, either a file or a folder

`plaintext network`: Bring your own or download from RegNetwork 2025

`pathway file`: e.g. from reactome

`interactions`: Ideally biogrid though intact also works, I used `BIOGRID-ALL-5.0.258`


### Generated by my scripts

`GRN_PATH`:
`plaintext network` of gene regulatory network created by `gene_regulatory/regulatory_network.py` with inputs:
* tf to gene grn
* tf to tf grn
* biomart mapping
* analysis gene names (to filter for existing genes)

`PATHWAY_FILE`:
csv file containing genes, pathway id, name and organism, with one row per gene, formatted by `preprocessing/format_pathway_file.py` with inputs:
* `pathway file` e.g. from Reactome

`VIRUS_EDGE_PATH`:

* intact interactions from `temporal_separation/intact_interactions.py`, 
* biogrid interactions extracted from the original `BIOGRID-ALL-5.0.258.mitab.txt` using `preprocessing/process_mitab.py`

`VIRUS_NODE_PATH`:

csv based node file based on the interactions file where each row has:
`id`, `taxonomy`, `entrez`, `name` + this header
